# Actualizar Noveria a la versión 5.2

1. **ANTES** de sustituir archivos, abrí tu partida actual y exportá una copia JSON en Palmarés y partida.
2. Descargá el ZIP `Noveria_V5_2_SOLO_MODIFICADOS.zip`, descomprimí y reemplazá en tu repositorio los archivos por sus mismos nombres. Importante: `season-experience.js` es un archivo NUEVO.
3. Guardá todos los archivos directamente en la raíz del repositorio (salvo las carpetas de recursos).
4. **No reemplaces `cloud-config.js`**: tu conexión con Joshua Cloud permanece intacta.
5. Confirmá cambios (Commit changes), esperá a que GitHub Pages los publique y recargá con Ctrl+F5 si seguís viendo la versión anterior.
6. Entrá a Semifinales y Recopa: verás el marcador GLOBAL por serie. Entrá a Periódico para la edición especial del campeón, y a Rueda de prensa para elegir liga, copa o fase final.
7. Verificá que Joshua Cloud diga sincronizado antes de abrir desde otro dispositivo.

No es necesario ejecutar otro SQL, crear otro proyecto de Supabase ni reiniciar el universo. La actualización no altera resultados ni campeones existentes; únicamente agrega presentación, ediciones históricas y decisiones contextuales.
